# يوسفي

محوّل ملفات يعمل داخل المتصفح بالكامل، مستوحى من فكرة Tangerine for Mac: اسحب الملف ثم اضغط مفتاحًا لتظهر عجلة الخيارات.

| المفتاح أثناء السحب | العجلة |
| --- | --- |
| `Shift` | تحويل الصيغة |
| `⌘` على Mac أو `Alt` | أدوات الملف (ضغط، قص، تغيير الحجم، ألوان، خلفية…) |
| `Control` | إجراءات (تنزيل، الرف، تكرار، معلومات، حذف) |

- افتح `index.html` في المتصفح مباشرة، فلا يحتاج إلى خادم أو تثبيت.
- الملفات لا تُرفع إلى أي مكان. المكتبات (jsPDF وJSZip وmarked وpdf.js) تُحمَّل من cdnjs عند أول استخدام.
- لوحة المفاتيح: `Enter` على ملف يفتح العجلة، والأسهم للتنقل، و`Tab` للتبديل بين العجلات.
- شاشات اللمس: الضغط المطوّل على الملف ثم السحب إلى الخيار.
